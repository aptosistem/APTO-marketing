# APTO POS — Sitio público

Landing de promoción. El código del producto está en un repositorio privado.

## Vista local

```bash
python -m http.server 8080
```

Abre http://localhost:8080/

## Publicación (GitHub Pages)

En el repo: **Settings → Pages → Source: Deploy from a branch → `main` → / (root)**.

La URL suele ser `https://aptosistem.github.io/APTO-marketing/` (ajusta usuario/org si aplica).
